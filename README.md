# Blog Pessoal

Blog pessoal desenvolvido com **React + TypeScript + Vite**.

## Funcionalidades

- Página inicial com boas-vindas
- Botões para criar e visualizar postagens

## Tecnologias

- React 19
- TypeScript
- Vite
- ESLint

## Como executar

```bash
npm install
npm run dev
```

O servidor será iniciado em `http://localhost:5173`.

## Build

```bash
npm run build
```

## Preview da build

```bash
npm run preview
```
